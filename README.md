# GATE CSE Planner

A private, browser-based progress tracker for the full GATE 2027 CSE syllabus.

## Use it

Open `index.html` in a modern browser. No installation, login, or server is required.

Your progress is saved in that browser on this device. Use **Export backup** in the sidebar periodically to download a copy of your tracker data.

## What it tracks

- 89 detailed topics across the 10 CSE sections provided
- Status for every topic: Not started, Learning, Practising, Revised, or Complete
- Revision counter per topic, with a 1 / 7 / 21-day revision queue
- PYQ count per topic
- Subject-level completion and PYQ coverage insights
- Optional GATE exam date and countdown
